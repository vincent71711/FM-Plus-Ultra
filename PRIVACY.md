# Privacy

File Manager Plus Ultra is a private-use derivative of Material Files. The mod
does not include analytics, advertising, Firebase, Crashlytics, telemetry, or
automatic diagnostic uploads.

## Data handling

- File names, paths, file contents, bookmarks, remote-server settings, and
  credentials remain on the device unless the user explicitly performs an
  operation involving another destination.
- Network access is used only for user-requested features such as SMB, FTP,
  SFTP, WebDAV, opening remote content, or checking an endpoint entered by the
  user.
- Remote services may log connection information according to their own
  configuration and policies. This app does not control those services.
- Android and other installed applications may receive files or metadata when
  the user explicitly opens, shares, or grants access to them.

## Diagnostics

The derivative does not send crash reports. Development diagnostics are
collected locally with Android debugging tools and must be reviewed before they
are retained or shared.
